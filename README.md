# MyClubSoftware Backend

## Getting started

1. Setup environment for development deployment:
    - Create a file in the root called ".env"
    - Add the following variables: ENVIRONMENT, DOMAIN, REGION, ACCOUNT, MEMBER_CERT_ARN, ADMIN_CERT_ARN, INTERNAL_INFRA_CERT_ARN

2. Run:
    - cli configure
    - npm run create-layers
    - npm run deploy
